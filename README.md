# us-market-boards

Live US market boards — the S&P 500 and a curated ETF universe — built the same
way as the Indian boards (`nifty-heatmap-web`, `nifty-ema-board`,
`nifty-pcr-tracker`, `fno-rollover`) and sharing their RRG mathematics.

**Live:** https://abhijeetbishayee-drb.github.io/us-market-boards/rrg.html

## Universe

- **Stocks** — the S&P 500 by GICS sector, generated by `scripts/refresh_universe.py`
  from **two independent sources** (the datasets.io constituents CSV and
  Wikipedia's constituents table). They must agree exactly on the symbol set
  and on every symbol's sector or the script aborts; it does not pick a winner,
  because a silent tiebreak is how a universe goes stale. Last agreed run:
  503 names, 11 sectors, zero disagreements.
- **ETFs** — 112 funds in 8 curated groups, `scripts/refresh_etfs.py`. Groups
  are hand-curated; only the labels come from Yahoo.
- **Sector series** — the eleven Select Sector SPDRs themselves, not baskets.
  They *are* the eleven GICS sectors, liquid and properly weighted.

## Corporate actions — and why there is far less machinery here

The Indian boards carry a curated corporate-action table because Yahoo's Indian
`close` is not split-adjusted and its split records carry the wrong date. The US
series is the opposite, measured over eight known splits (NVDA 10:1, AAPL 4:1,
AMZN 20:1, GOOGL 20:1, TSLA 3:1, CMG 50:1, WMT 3:1, MSTR 10:1): every ex-date
gap is an ordinary daily move, so the series is already adjusted and correctly
dated. **A repair layer here would invent the cliff it exists to remove.**

Spin-offs are the real question and Yahoo hands us the number: it prices them in
as a *fractional* split whose ratio is the size of the separation. Above
`ECONOMIC_SPLIT = 0.20` of the parent removed, usable history starts at the
event; below it, the back-adjusted series is kept. See `us_market_core/corp_events.py`
for the measured distribution either side of that line.

**Nothing is ever inferred from price.** Moderna rose 177% in one session on
2026-08-19 — by size indistinguishable from a reverse split, and entirely real
(first positive Phase 3 for a personalised mRNA cancer vaccine). Unexplained
gaps are printed in the build log and left alone. The single exception is a
separation Yahoo has not yet published, entered by hand in `OVERRIDES` against
the company's own filing — currently Corteva's Vylor spin-off of 2026-10-01.

## Build

```bash
pip install -r requirements.txt
git submodule update --init                 # nifty-heatmap-core: shared RRG maths
python3 scripts/build_rrg.py --force
```

`nifty-heatmap-core` is imported rather than copied. Hand-copying shared logic
between repos is what produced the web-vs-Android parity bug that created that
package in the first place.

## Refresh

GitHub's `schedule` trigger is unreliable (observed 1–2h late, once 7h30m), so
the daily rebuild is driven by an external pinger hitting the `workflow_dispatch`
REST API, exactly as the Indian boards are. `build_rrg.py --if-stale` decides
staleness itself, so late or duplicate pings are no-ops.

All times are computed in `America/New_York`, never a fixed offset — the US has
two DST transitions a year.
